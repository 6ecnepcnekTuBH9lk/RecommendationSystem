# STAT-UI-POLISH-01: графики и пояснения

Актуализация STAT-UI-STRUCTURE-01: три графика сохранены, названия их осей убраны; денежные tooltips магазинов показывают два знака. Восемь временных панелей отключены. Контракт будущего пояснения — строго под своей таблицей, градиентная question.png 20 px, отступ до текста 8 px, по умолчанию свёрнуто. Полный аудит: [statistics_ui_structure_audit.md](statistics_ui_structure_audit.md).

Изменения относятся к presentation вкладок «Заказы» и «Товары».
Расчётные агрегаты, DTO результата, fingerprint, кеш и INDEXED не меняются.
Вкладка «Клиенты», включая её графики и подразделы, остаётся прежней.

## Три графика

- Магазины/каналы RUB и KZT: TOP-10 по сохранённой сумме из store_statistics.
  Сортировка по точному Decimal, затем стабильному ID и названию.
  Для отрицательного ключа сортировки используется copy_negate(), которое
  не округляет Decimal даже при числе значащих цифр выше текущей точности контекста.
- Категории: TOP-10 по числу покупок из product_category_rows(result).
  При равенстве сортировка по коду. Одноимённые категории различаются кодами.
  Незаполненная категория остаётся самостоятельной. Родительские строки не добавляются.
- Значения денег и точные подсказки сохраняются в ChartData как Decimal.
  Штатный Qt Charts преобразует их в float только при отрисовке; HTML сохраняет точные строки.
- Графики подключены как ReportBlock("chart") перед полными таблицами.
  Состав, порядок и количество строк таблиц не меняются. Используются штатные цвета,
  подсказки, горизонтальные столбцы и обработка пустого результата.

## Раскрывающиеся пояснения

Тексты централизованы в statistics_table_explanations.py.
Текущий TABLE_EXPLANATIONS пуст. Ниже исторические ID восьми снятых назначений; будущая связь задаётся семантическим table_id в presentation-блоке:
она не зависит от заголовка и позиции таблицы.

| ID | Таблица |
|---|---|
| orders.basket | Корзина заказа |
| orders.financials | Финансовые показатели |
| orders.stores.RUB | Магазины и каналы — RUB |
| orders.stores.KZT | Магазины и каналы — KZT |
| orders.payments | Оплата |
| orders.line_statuses | Статусы позиций |
| products.purchased | Популярные товары по покупкам |
| products.categories | Категории товаров |

Остальные таблицы не получают панели автоматически. Ключевые определения сверены
с OrderAggregates и ProductAggregates: позиции отличаются от единиц и уникальных заказов;
средняя сумма делится на число заказов; у заказа может быть несколько способов оплаты.

StatisticsTableExplanation — небольшой независимый Qt-компонент.
Он свёрнут по умолчанию; кнопка поддерживает фокус и пробел, checked-состояние
и доступное название с состоянием панели. Стрелка меняет направление.
Word wrap и height-for-width поддерживают изменение ширины и высоты.
Цвета берутся из существующей Material-палитры и обновляются при смене темы.

HTML использует нативные details/summary без open, с безопасно экранированным
текстом и теми же определениями. В XLSX новые пояснения не вставляются:
прежняя заметка о категориях остаётся на прежнем месте, а GUI/HTML показывают
её обычным независимым методологическим текстом; временная панель отключена. Предыдущее незакоммиченное изменение этой заметки сохранено.

## Проверки

test_statistics_ui_polish.py проверяет валюты, TOP-10, точные деньги,
стабильную сортировку, категории, полноту таблиц, порядок график/панель/таблица,
пустые данные, клавиатуру, независимость панелей, геометрию и обе темы,
GUI/HTML и синтетический ZIP из двух файлов без доступа к исходникам и SQL.
Существующие тесты обновлены только для количества графиков и нового размещения пояснений.
