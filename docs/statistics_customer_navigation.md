# Навигация клиентской статистики

Вкладка «Клиенты» содержит штатный QTabWidget и пять независимых QScrollArea:
overview → purchases → money → rfm → cohorts.

- overview: клиентская база, демография всех клиентов, активность и отдельный портрет покупателей.
- purchases: покупательская активность, подтверждённые покупки, интервалы и полное сравнение политик.
- money: существующие блоки RUB и KZT, раздельно.
- rfm: компактный RFM после STAT-UI-POLISH-01.
- cohorts: компактные когорты после STAT-UI-POLISH-01.

grouped_buyer_sections() назначает группу при создании секции. Заголовки для маршрутизации не анализируются.
buyer_sections() возвращает прежний упорядоченный список секций для существующих XLSX/HTML.
Переключение не обращается к данным; выбранная группа хранится только в живом GUI и сохраняется при render().
Скроллы сохраняются при переключении страниц. Отрисовка нового результата пересоздаёт страницы.

Будущая задача, здесь НЕ реализована: единая кнопка экспорта и ZIP с агрегированными XLSX/HTML
и детальными XLSX покупателей; при миллионах строк — дополнительные листы или файлы без потерь
и дублирования. CSV в целевом едином экспорте не использовать. Действующие экспортёры,
кнопки, CSV/ZIP-контракты и форматы текущей задачей не меняются.
